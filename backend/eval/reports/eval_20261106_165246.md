### tm_001｜time_compare｜期望 SQL
- 问题：活动日当天转化率比前 7 天均值高多少
- 实际 action：sql；attempts：1
- 原因：列数不同：gold=3 / pred=1
- 生成 SQL：
```sql
WITH p AS (SELECT max_dt AS promo_dt FROM meta_dataset_range WHERE id = 1), promo AS (SELECT COUNT(DISTINCT CASE WHEN behavior_type = 'buy' THEN user_id END) AS buy_users, COUNT(DISTINCT CASE WHEN behavior_type = 'pv' THEN user_id END) AS uv FROM dwd_behavior_fact WHERE dt = (SELECT promo_dt FROM p)), base AS (SELECT COUNT(DISTINCT CASE WHEN behavior_type = 'buy' THEN user_id END) AS buy_users, COUNT(DISTINCT CASE WHEN behavior_type = 'pv' THEN user_id END) AS uv FROM dwd_behavior_fact WHERE dt BETWEEN (SELECT DATE_SUB(promo_dt, INTERVAL '7' DAY) FROM p) AND (SELECT DATE_SUB(promo_dt, INTERVAL '1' DAY) FROM p)) SELECT ROUND((promo.buy_users / NULLIF(promo.uv, 0) - base.buy_users / NULLIF(base.uv, 0)) / NULLIF(base.buy_users / NULLIF(base.uv, 0), 0), 4) AS promo_conversion_lift FROM promo, base LIMIT 1000
```
- gold SQL：
```sql
WITH p AS (SELECT max_dt AS promo_dt FROM meta_dataset_range WHERE id = 1), promo AS (SELECT COUNT(DISTINCT CASE WHEN behavior_type = 'buy' THEN user_id END) AS buy_users, COUNT(DISTINCT CASE WHEN behavior_type = 'pv' THEN user_id END) AS pv_users FROM dwd_behavior_fact WHERE dt = (SELECT promo_dt FROM p)), base AS (SELECT COUNT(DISTINCT CASE WHEN behavior_type = 'buy' THEN user_id END) AS buy_users, COUNT(DISTINCT CASE WHEN behavior_type = 'pv' THEN user_id END) AS pv_users FROM dwd_behavior_fact WHERE dt BETWEEN (SELECT DATE_SUB(promo_dt, INTERVAL 7 DAY) FROM p) AND (SELECT DATE_SUB(promo_dt, INTERVAL 1 DAY) FROM p)) SELECT ROUND(promo.buy_users / NULLIF(promo.pv_users, 0), 4) AS promo_rate, ROUND(base.buy_users / NULLIF(base.pv_users, 0), 4) AS base_rate, ROUND((promo.buy_users / NULLIF(promo.pv_users, 0) - base.buy_users / NULLIF(base.pv_users, 0)) / NULLIF(base.buy_users / NULLIF(base.pv_users, 0), 0), 4) AS lift FROM promo, base
```
